# Enxoval da Alice 🎀

Aplicativo pessoal (PWA) para organizar o enxoval de bebê por fases de crescimento —
recém-nascida até 12 meses — como um álbum a completar.

- Fases com quantidades sugeridas e anéis de progresso
- Fotos das peças e das etiquetas, com valor pago e marca
- Leitura de etiqueta por IA (Claude) — a chave fica somente no aparelho
- Moeda em US$ ou R$, tamanhos Brasil × EUA
- Funciona offline e gera PDF da lista

**Privacidade:** este repositório contém apenas o código do app. Fotos, valores e a
chave da IA ficam guardados exclusivamente no aparelho de quem usa — nada é enviado
para este site.
